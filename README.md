# 고객 안내 콘텐츠 저장소

이 저장소는 챗봇이 고객에게 보여주는 **안내 페이지(HTML)와 이미지, PDF 파일**을 관리하는 곳입니다.
개발 지식이 없어도 이 문서만 보면 "여기에 뭐가 있고, 어떻게 관리하는지" 알 수 있도록 정리했습니다.

## 이 저장소는 무엇을 하나요?

고객이 챗봇에서 "연결이 안 돼요", "휴일 설정은 어떻게 하나요" 같은 질문을 하면,
챗봇은 여기 있는 안내 페이지 링크를 답변에 포함해서 보여줍니다.

즉, 이 저장소의 `manuals` 폴더 안에 있는 파일들이 **고객이 실제로 보는 화면**입니다.
챗봇 프로그램을 만드는 개발팀은 별도 저장소에서 "어떤 질문에 어떤 안내를 보여줄지" 연결하는
작업을 하고, 이 저장소는 그 안내 화면의 내용(문구, 이미지, PDF)만 관리합니다.

## 폴더 구성

```
manuals/
├── leaf-customer-guide.html                        ← 리프 제품 종합 안내
├── caps-customer-guide.html                         ← 캡스 제품 종합 안내
├── holiday-setting-guide.html                       ← 휴일 설정 안내
├── smart-reservation-add-schedule-guide.html        ← 스마트예약 추가 안내
├── smart-reservation-edit-schedule-guide.html       ← 스마트예약 수정 안내
├── smart-reservation-duplicate-check-guide.html     ← 스마트예약 중복 확인 안내
├── assets/     ← 안내 페이지에 들어가는 사진, 그림, 움직이는 이미지(gif)
├── files/      ← 고객에게 제공하는 PDF 매뉴얼
└── content-manifest.json   ← 위 6개 안내 페이지 목록과 버전 정보
```

각 HTML 파일은 하나의 "고객 안내 페이지"라고 생각하면 됩니다. 예를 들어
`holiday-setting-guide.html`을 열면 휴일 설정 방법을 안내하는 화면이 그대로 나옵니다.

## 안내 페이지 내용을 수정하고 싶을 때

1. **어떤 페이지를 고칠지 정합니다.** 위 6개 파일 중 하나입니다.
2. **그 페이지 안의 문구, 이미지 경로를 확인합니다.** 이미지는 `assets` 폴더,
   PDF는 `files` 폴더 안에 있는 파일을 참조하고 있습니다.
3. **해당 파일만 고칩니다.** 관련 없는 다른 페이지나 파일은 건드리지 않습니다.
4. **`content-manifest.json`의 버전 번호를 올립니다.** (아래 "버전 관리" 참고)
5. 수정한 페이지를 웹 브라우저로 직접 열어서 화면이 잘 보이는지, 링크와 버튼이
   제대로 동작하는지 확인합니다.

파일 이름은 절대 바꾸지 않습니다. 챗봇 개발팀이 이 이름을 기준으로 연결해두었기 때문에,
이름이 바뀌면 챗봇에서 안내 페이지가 열리지 않게 됩니다.

## 새 안내 페이지를 추가하고 싶을 때

1. 기존 6개 페이지와 내용이 겹치지 않는지 먼저 확인합니다.
2. 새 파일 이름은 영문 소문자와 하이픈(-)만 사용합니다. (예: `new-feature-guide.html`)
3. 관련 이미지는 `assets` 폴더에, PDF는 `files` 폴더에 넣습니다.
4. 새 HTML 파일을 `manuals` 폴더 바로 아래에 추가합니다.
5. `content-manifest.json`의 안내 목록에 새 페이지 정보를 추가합니다.
6. 챗봇 개발팀에게 새로 추가한 파일 이름과 어떤 제품(리프/캡스)에 대한 안내인지 알려줍니다.
   (챗봇이 이 페이지를 언제 보여줄지는 개발팀이 별도로 연결 작업을 해야 합니다.)

## 버전 관리 (`content-manifest.json`)

이 파일은 "지금 서비스되고 있는 안내 페이지 목록과 버전"을 적어두는 문서입니다.
숫자는 `1.0.0`처럼 세 자리로 되어 있고, 아래 기준으로 올립니다.

- **문구나 이미지만 살짝 고쳤을 때** → 맨 뒤 숫자를 올립니다. (예: 1.0.0 → 1.0.1)
- **새 안내 페이지를 추가했을 때** → 가운데 숫자를 올립니다. (예: 1.0.1 → 1.1.0)
- **기존 파일 이름이나 경로 구조를 크게 바꿔야 할 때** → 맨 앞 숫자를 올리고,
  반드시 미리 챗봇 개발팀과 상의합니다. (예: 1.1.0 → 2.0.0)

## 수정 후 꼭 확인해야 할 것들

- `content-manifest.json`에 적힌 안내 페이지 파일이 실제로 모두 존재하는지
- 안내 페이지 안에서 참조하는 이미지, GIF, PDF, 다른 안내 페이지 링크가 모두 정상인지
- 컴퓨터 화면과 휴대폰 화면 양쪽에서 글자와 버튼이 잘리지 않는지
- 뒤로 가기, 탭 전환, 팝업(모달), PDF 열기, 전화 연결, 외부 링크가 잘 동작하는지
- 기존 6개 안내 페이지의 파일 이름이 그대로인지

## 내용을 작성할 때 지켜야 할 규칙

- 리프 제품 안내와 캡스 제품 안내는 서로 섞이지 않도록 합니다.
- 전원 차단, 케이블 분리, 초기화처럼 고객이 직접 하는 중요한 절차는
  운영팀이 확인한 문구만 사용합니다. 임의로 바꾸지 않습니다.
- 비밀번호, 인증 토큰, 고객 개인정보, 내부 시스템 주소 같은 민감한 정보는
  절대 안내 페이지에 넣지 않습니다.

## 확인 방법 (터미널을 쓸 줄 아는 경우)

저장소 최상위 폴더에서 아래 명령어로 확인할 수 있습니다.

```bash
# manuals 폴더 안의 모든 파일 목록 보기
find manuals -type f | sort

# content-manifest.json 파일에 문법 오류가 없는지 확인
python3 -m json.tool manuals/content-manifest.json >/dev/null

# 내 컴퓨터에서 안내 페이지 미리보기 (실행 후 브라우저에서 http://localhost:8000 으로 접속)
python3 -m http.server 8000 --directory manuals
```

## 궁금한 점이 있다면

- "이 안내 페이지가 챗봇에서 언제 보이나요?" 같은 질문은 챗봇 개발팀에 문의합니다.
  (FAQ 연결, 검색 로직은 이 저장소가 아니라 챗봇 개발팀이 관리합니다.)
- 안내 문구나 화면 디자인에 대한 질문은 운영팀 담당자에게 문의합니다.
